# Bootstrap Carousel — Componentes de Slider

Projeto de estudo dedicado à construção e configuração de **carrosséis responsivos com Bootstrap**.

O arquivo reúne diferentes variações do componente Carousel para demonstrar controles, indicadores, legendas e transições.

## Exemplos implementados

- slider automático simples;
- carousel com controles anterior/próximo;
- carousel com indicadores;
- carousel com legendas sobre as imagens;
- transição com efeito `carousel-fade`.

## Tecnologias

- HTML5
- Bootstrap 4
- Font Awesome
- jQuery e Popper.js como dependências da versão do Bootstrap utilizada no projeto

## Objetivo de aprendizado

O projeto foi criado para entender a estrutura dos componentes Bootstrap e como configurar diferentes comportamentos de navegação e apresentação de conteúdo visual.

## Estado do projeto

O código original referencia imagens em uma pasta `img/` que não está atualmente presente no repositório. Por isso, esta versão é mantida principalmente como registro de estudo e pode exigir a inclusão dos assets para execução visual completa.

## Contexto de portfólio

Este projeto representa uma etapa da minha evolução em desenvolvimento web e no uso de componentes reutilizáveis para construção de interfaces responsivas.
